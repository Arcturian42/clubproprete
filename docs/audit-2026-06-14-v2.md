## 2. Findings priorisés

### 🔴 P0 — à corriger vite (faible effort, impact réel)

| # | Sév. | Fichier | Problème | Fix |
|---|---|---|---|---|
| F1 | 🟠 | `app/api/upload/route.ts` | **Validation upload trop stricte** : `detectedType !== file.type` rejette des fichiers valides quand le navigateur déclare `image/jpg` / `image/pjpeg` / type vide. **C'est la cause des `400` observés.** | Supprimer la clause `!== file.type` ; se fier au type *sniffé* (déjà dans `ALLOWED_TYPES`). |
| F2 | 🟠 | `auth.ts` | **OAuth : `email_verified` mal asserté** — on rejette seulement `=== false`. Un claim manquant/`undefined` passe et lie l'identité Google à un compte mot-de-passe existant. | Exiger positivement `profile?.email_verified === true`. |
| F3 | 🟠 | `auth.ts` | **`signIn` non protégé** : si la création/req DB échoue (ou collision unique sur 1er login concurrent → P2002), l'exception remonte en erreur générique au lieu d'un échec propre. | `try/catch` → `return false` ; sur P2002, re-fetch l'utilisateur existant. |

### 🟡 P1 — important

| # | Sév. | Sujet | Détail |
|---|---|---|---|
| F4 | 🟡 | **Canonical sur mauvais domaine** | En prod, `canonical`/OG/JSON-LD pointent vers `clubproprete.vercel.app` alors que le site vit sur `www.clubproprete.com`. → définir `NEXT_PUBLIC_APP_URL=https://www.clubproprete.com` (Vercel, Production) + redeploy. |
| F5 | 🟡 | **JSON-LD non échappé** (`components/json-ld.tsx`) | `JSON.stringify` injecté sans échapper `<`. Inoffensif aujourd'hui (données statiques) mais **XSS latente** si un titre d'article/DB y passe (breadcrumb, Article). → `.replace(/</g, '\\u003c')`. |
| F6 | 🟡 | **Pas de tests sur OAuth/upload** | Les 2 nouvelles features critiques n'ont aucun test. → e2e/integration ciblés. |
| F7 | 🟡 | **Observabilité absente** | Pas de Sentry/APM ni logs structurés ; on a dû lire les logs Vercel à la main pour diagnostiquer l'upload. |

### 🟢 P2 — dette / amélioration

| # | Sujet | Détail |
|---|---|---|
| F8 | **Perf images** | 11 fichiers en `<img>` (20 warnings lint) : pas de `next/image` → CLS/LCP dégradés sur fiches/blog. Nécessite `images.remotePatterns` (domaine Blob + tiles). |
| F9 | **Rate-limit en mémoire** | `lib/rate-limit.ts` se réinitialise par cold start serverless et se contourne (IP `x-forwarded-for` falsifiable). → Upstash Redis + IP plateforme. |
| F10 | **Preuve sociale réelle** | Home : ligne « membres fondateurs » en place mais aucun témoignage/logo réel (à activer dès les premiers membres — ne rien inventer). |
| F11 | **CSP `script-src 'unsafe-inline'`** | Affaiblit la défense XSS en prod ; migrer vers nonce à terme. |
